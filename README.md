## ✨ Features

- Interactive grid where you can toggle cells by clicking
- Play/Pause simulation controls
- Step-by-step evolution
- Speed adjustment for simulation
- Reset and randomize grid options
- Responsive design that works on desktop and mobile
- Classic Conway's Game of Life rules implementation

## 🎮 Game Rules

Conway's Game of Life follows these simple rules:
1. **Underpopulation**: Any live cell with fewer than two live neighbors dies
2. **Survival**: Any live cell with two or three live neighbors survives
3. **Overpopulation**: Any live cell with more than three live neighbors dies
4. **Reproduction**: Any dead cell with exactly three live neighbors becomes alive
